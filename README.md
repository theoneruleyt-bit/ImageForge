# ImageForge V0.8 — Before/After + Output Predictor

Fixes batch output collisions by assigning every processed image a unique MediaStore filename. The Batch screen also shows the selected and queued counts explicitly. Free mode processes up to 5 images sequentially and saves each successful output to `Pictures/ImageForge`.


## V0.8 Privacy Cleaner
Reads supported EXIF privacy fields (GPS, device/camera, capture date, software and lens) and creates a new re-encoded privacy-safe copy without EXIF metadata. The original file is never modified.


## V0.8 Recipes / Workflow Engine
Built-in recipes, locally saved custom workflows, one-tap Studio application, format/quality/max-dimension/privacy settings.
