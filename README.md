# ImageForge V0.5 — Batch Engine

ImageForge now includes a real on-device batch workflow.

## V0.5
- Select multiple images with Android Photo Picker
- Free batch processing for up to 5 images
- Shared JPEG / PNG / WebP output setting
- Shared quality and maximum-dimension controls
- Sequential processing to reduce peak memory pressure
- Live progress, success and failure counts
- Outputs saved to `Pictures/ImageForge`

Existing V0.4.1 Smart Target Size and single-image processing remain available.
